Here’s a fresh-start installation guide for this Streamlit Naive Bayes Visualization App.

**1. Create A New Folder**
```bash
mkdir ML-project
cd ML-project
```

**2. Create A Virtual Environment**
Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**3. Install Dependencies**
```bash
python -m pip install --upgrade pip
python -m pip install streamlit pandas numpy plotly scikit-learn
```

**4. Create `app.py`**
Create a file named `app.py` in the project folder and paste your app code into it.

**5. Run The App**
```bash
python -m streamlit run app.py
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:8501
```

**Optional `requirements.txt`**

Create a file named `requirements.txt`:

```txt
streamlit
pandas
numpy
plotly
scikit-learn
```

Then install everything with:

```bash
python -m pip install -r requirements.txt
```

For this project, those five packages are the core requirements.
